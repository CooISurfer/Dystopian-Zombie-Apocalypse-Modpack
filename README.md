# CoolSurfer's Dystopian Zombie Apocalypse Modpack
Forget everything you knew about survival. The dead walk, the nights are unforgiving, and the infected are everywhere, taking out the last living survivors one by one. This is no longer Minecraft. This, is the end of the world

The version for this mod is Forge 1.20.1. A few mods are disabled like Iris shaders and others and are completely optional. To ensure you have the intended experience, when creating your Survival or Hardcore world, make sure you configure the Lost Cities tab. You can find it in World Options. Choose either the default experience on "test_world" or play the advanced map with a post-apocalyptic metro by clicking the "default" button once or twice
